# Финальная Дорожная Карта Выхода в Продакшен (100% Production Readiness Roadmap)

Документ описывает оставшиеся 10–12% задач для доведения проекта **MCP Rooms Marketplace (`LeonidYasin/mcp-rooms-googleai-2`)** до 100% готовности к финальному релизу и развёртыванию на боевой инфраструктуре (VPS/Cloud).

---

## 🎯 Цели и разделение задач по сессиям AI-Агентов

### 🟢 Модуль 1: Безопасность стримов и тикетная авторизация SSE (Ticket-based SSE Auth)
- **Ответственная сессия:** Сессия A (Jules) — **В РАБОТЕ**
- **Описание:** Исключение утечки токенов доступа из URL `GET /api/rooms/:id/stream?access_token=...` в прокси-логи.
- **Подзадачи:**
  1. Реализовать эндпоинт `POST /api/rooms/:id/ticket` для генерации короткоживущего одноразового тикета подключения (TTL 30 секунд).
  2. Проверять тикет `?ticket=...` в SSE-стриме `/api/rooms/:id/stream` вместо применения сырого Bearer токена.
  3. Написать unit-тесты в `tests/sse-ticket-auth.test.ts`.

---

### 🔵 Модуль 2: Автоматизированные Headless E2E тесты (Playwright E2E)
- **Ответственная сессия:** Сессия A (Jules) — **В РАБОТЕ**
- **Описание:** Полное E2E тестирование визуального интерфейса React и взаимодействия с сервером.
- **Подзадачи:**
  1. Настроить Playwright тестовый скрипт для эмуляции поведения пользователя и AI-агента.
  2. Проверить сценарий публикации объявления, создания комнаты переговоров и получения ответов.
  3. Интегрировать автоматический запуск Playwright в CI (GitHub Actions).

---

### 🟡 Модуль 3: Инфраструктурный Deployment Runbook & Caddy/Reverse Proxy Config
- **Ответственная сессия:** Сессия A (Jules) — **ЗАВЕРШЕНО (PR #29)**
- **Описание:** Финальная конфигурация обратного прокси для безопасного TLS/HTTPS трафика.
- **Подзадачи:**
  1. Подготовить конфигурационный файл `Caddyfile` / `nginx.conf` с настройками WebSocket/SSE проксирования и сжатия.
  2. Обновить `docs/deployment.md` автоматическими командами развёртывания в один клик.
  3. Настроить регулярный экспортер метрик здоровья сервера (`GET /api/llm/status` + `systemd/docker healthcheck`).
